# Irevive — сайт на специализиран сервиз за Apple продукти

Статичен сайт (HTML + CSS + JavaScript, без билд процес и без зависимости).
Може да се качи на всеки хостинг, GitHub Pages, Netlify, Vercel или Cloudflare Pages
чрез просто копиране на файловете.

## Структура

```
index.html          Начална страница
iphone.html         Ремонт на iPhone (услуги + ориентировъчни цени)
ipad.html           Ремонт на iPad
mac.html            Ремонт на Mac / MacBook / iMac
apple-watch.html    Ремонт на Apple Watch
airpods.html        Ремонт на AirPods
uslugi.html         Пълен списък с услуги и цени
kak-raboti.html     Процес, куриери и гаранционни условия
za-nas.html         За нас
kontakti.html       Контакти + форма за запитване
404.html            Страница при липсваща връзка
css/styles.css      Всички стилове
js/main.js          Мобилно меню, анимации, форма
assets/favicon.svg  Икона на сайта
robots.txt          Инструкции за търсачките
sitemap.xml         Карта на сайта
```

## Какво трябва да смените преди пускане

Данните по-долу са попълнени с примерни стойности. Заменете ги навсякъде
(най-лесно с търсене и заместване във всички `.html` файлове):

| Какво | Примерна стойност | Къде се среща |
|---|---|---|
| Телефон (за показване) | `+359 88 000 0000` | всички страници |
| Телефон (връзка `tel:`) | `+359880000000` | всички страници |
| Viber връзка | `viber://chat?number=%2B359880000000` | всички страници |
| Имейл | `info@irevive.bg` | всички страници |
| Адрес | `гр. София, бул. „Витоша“ 1` | футър, `kontakti.html` |
| Работно време | 10:00 – 19:00 / 10:00 – 14:00 | футър, `kontakti.html` |
| Домейн | `https://irevive.bg` | `<link rel="canonical">`, `sitemap.xml`, `robots.txt` |

Пример с една команда (Linux/macOS):

```bash
grep -rl "+359 88 000 0000" . --include="*.html" | xargs sed -i 's/+359 88 000 0000/ВАШИЯТ ТЕЛЕФОН/g'
```

### Цени

Всички цени са **ориентировъчни примери** и трябва да бъдат заменени с вашата
реална ценова листа. Намират се в таблиците `<table class="price">` на
страниците за устройства и в картите с услуги в `uslugi.html` и `index.html`.
Посочени са в евро (€) с включено ДДС — ако предпочитате друга валута или
двойно обозначаване, редактирайте текстовете на същите места.

Под всяка таблица има бележка, че цените не са публична оферта — препоръчваме
да я запазите.

## Форма за запитване

Формата в `kontakti.html` работи **без сървър**: при изпращане съставя готово
съобщение и го отваря в имейл клиента на посетителя. Основният канал за
запитвания е Viber бутонът.

За автоматично изпращане на имейл добавете безплатна услуга за форми:

1. Регистрирайте се в [Formspree](https://formspree.io) (или Netlify Forms).
2. В `kontakti.html` добавете `action` и `method` на формата:

```html
<form class="form" id="inquiry-form" action="https://formspree.io/f/ВАШИЯТ_КОД" method="post">
```

Скриптът разпознава `action`, започващ с `http`, и оставя браузъра да изпрати
формата нормално.

## Локално стартиране

Достатъчно е да отворите `index.html` в браузър. За по-точна проверка:

```bash
python3 -m http.server 8000
# след това отворете http://localhost:8000
```

## Качване на GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`
2. Изберете клона и папка `/ (root)`
3. Сайтът се публикува на `https://<потребител>.github.io/<хранилище>/`

При собствен домейн добавете файл `CNAME` със съдържание `irevive.bg`.

## Технически бележки

- Няма външни зависимости, шрифтове или скриптове — сайтът работи и офлайн.
- Илюстрациите на устройствата са вградени SVG, така че са ясни на всеки екран.
- Добавени са структурирани данни (`LocalBusiness` и `FAQPage`) за по-добро
  представяне в Google.
- Стиловете са с CSS променливи в началото на `css/styles.css` — цветовете на
  марката се сменят от едно място (`--brand`, `--viber`, `--ink`).
- Секцията с отзиви умишлено липсва — добавете я, когато имате реални отзиви
  от клиенти.

## Качване във Vercel

Сайтът е статичен — Vercel не се нуждае от билд команда. В хранилището има
`vercel.json` с готовите настройки (кеширане и базови заглавия за сигурност).

### Импорт от GitHub (препоръчително)

1. Отворете [vercel.com/new](https://vercel.com/new)
2. **Import Git Repository** → изберете `adelinachopanowa-eng/Irevive`
3. Framework Preset: **Other** (Build Command и Output Directory се оставят празни)
4. **Deploy**

След това всяко качване (`git push`) в основния клон се публикува автоматично.

Забележка: в момента основният клон на хранилището е
`claude/irevive-apple-repair-site-gw4h13`. Vercel ще го използва като
production клон. Ако предпочитате `main`, слейте клона в `main` и сменете
Production Branch в Settings → Git.

### Собствен домейн

Settings → Domains → Add → `irevive.bg`. Vercel показва кои DNS записи да
добавите при регистратора на домейна. След това заменете `https://irevive.bg`
в `sitemap.xml`, `robots.txt` и в `<link rel="canonical">` на страниците, ако
домейнът е различен.
